# Melodia

Landing page responsiva criada para apresentar o aplicativo fictício de música Melodia.

O projeto destaca os principais benefícios do aplicativo, suas funcionalidades, depoimentos de usuários e um formulário para cadastro de e-mail.

## Tecnologias utilizadas

- HTML5 para a estrutura e o conteúdo da página
- Tailwind CSS para layout, espaçamento, cores e responsividade
- CSS3 para a identidade visual, animações e efeitos personalizados
- JavaScript para o menu móvel, cabeçalho transparente, player de áudio, formulário e modal de privacidade
- Font Awesome para os ícones
- Google Fonts para as famílias Archivo Black e DM Sans

## Funcionalidades

- menu fixo e responsivo
- mudança visual do cabeçalho durante a rolagem
- navegação entre as seções da página
- reprodução real de uma faixa com play, pause, tempo e controle de progresso
- conteúdo responsivo para celular, tablet e computador
- validação de e-mail e autorização no formulário
- mensagem de erro ou sucesso após a tentativa de cadastro
- modal com a política de privacidade

O formulário funciona como uma demonstração front-end. Ele valida os dados e mostra uma resposta ao usuário, mas não envia nem armazena informações em um servidor.
